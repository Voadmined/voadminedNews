# Voadmined News Information
News, release notes and credits for [my website](https://voadmined.netlify.app). You can view all the data by opening the message modal or pressing the `n` key while on the website's home page.
## news.json
The `news.json` file contains all news items and update logs/release notes for the website.
## credits.json
The `credits.json` file contains the credits and at least one social media link for people who have contributed to the website.
